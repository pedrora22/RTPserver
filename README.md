# RTP Streaming Manual em Python

Projeto simples de streaming RTP manual utilizando:
- Python
- UDP
- OpenCV
- Encapsulamento RTP manual

O projeto possui:
- `server.py` → envia os frames via RTP
- `client.py` → recebe e exibe os frames

---

# Instalação

1. Clone o repositório.
2. execute para baixar as dependencias:
   pip install -r requirements.txt
3. inicie o servidor:
   python server.py
4. inicie o cliente:
   python client.py
